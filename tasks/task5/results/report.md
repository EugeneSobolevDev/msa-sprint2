- Настроена маршрутизация трафика с Istio.
- Добавлено две версии сервиса:
    - v1 — основная версия сервиса.
    - v2 — новая версия с возможностью включения фича-флагов через добавление переменной окружения ENABLE_FEATURE_X с любым значением
- Настроена Istio-маршрутизация:
    - Трафик разделен между версиями через канареечный Release (90% трафика на v1, 10% на v2).
    - Добавлен fallback-маршрут, который перенаправляет трафик с v1 на v2, если v1 возвращает ошибку.
- Настроены Retry и Circuit Breaking.
  Использован DestinationRule для настройки Retries и Circuit Breaking для защиты от ошибок.
- Настроены фича-флаги через заголовки запросов. При запросе на сервис v1 http://localhost:8080/ping с ключом "X-Fallback: true" приложение сгенерирует 503 ошибку (также используется для проверки fallback)
